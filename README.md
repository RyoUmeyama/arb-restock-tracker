## ☁️ 実行体制（GitHub Actionsフル稼働・2026-09-09現況）

- **GitHub Actions（public・分数無制限）が唯一の実行環境**。cronは**毎時2回（`7,37 * * * *`）**、
  1起動は `LOOP_COUNT=8 × LOOP_INTERVAL=420秒` のジョブ内ループで**約68〜75分**粘る。
  concurrency（`gunpla-restock`・cancel-in-progress: false）で同時実行は1本に抑えられ、
  待機中の起動が前ジョブ終了直後に連結するため、**実効約8.5分ごとのパスがほぼ途切れず続く**
  （2026-08-19に毎時4回→2回へ整理。15分間隔だと後発がconcurrency待ちで捨てられていた）。
  ポーリングを密にしたい場合はcronではなく `LOOP_INTERVAL` を下げる

## 📱 X投稿用ブロック（x_post/）

再販検知の通知に、Xにコピペできる投稿文を添える機能。**X APIは使わない**（投稿は手動）。

- **書式**: 在庫速報として「何が・いくらで・どこに」だけを4行で出す。
  口語の煽りや注意書きは載せない（人間らしさより情報密度を優先する方針）

      商品名
      定価5,940円 Amazon
      https://...
      #ポケカ

- **文字数**: Xの重み付き280カウント（全角2・半角1・URLは実長に関わらず23）に収まるよう
  商品名を自動で切り詰める
- **正確性**: 検知できているのは「ページ上で在庫/告知が動いた」ことだけなので、
  定価で買えるとは書かない。価格は必ず**「定価」を冠して**出す（`5,940円`単体だと
  その値段で買えると誤読されるため）。お知らせ系は`再販告知`と明示して在庫と区別する
- **アフィリエイト**: `AMAZON_ASSOCIATE_TAG` を設定するとAmazonリンクに`tag=`を付与し、
  **同時に`#PR`を自動で付ける**（Amazonアソシエイト規約の開示義務。タグだけ付いて
  開示が漏れる事故を構造的に防ぐ）。楽天等のAmazon以外のURLは対象外

将来自動投稿へ移す場合も `build_post_text()` の出力をそのままAPIに渡せる。
その場合の費用目安は**リンク付き$0.20/件**（リンクなしは$0.015/件）。

## 📊 データ源と在庫判定（事前検証で確定）

### 判定方式（method）
- **toei_stock_status**（OP-16等）: 東映アニメ公式の商品ページ埋め込みJSONの
  `stock_status` を読む。`"0"` なら在庫なし、それ以外なら在庫あり。Shift_JIS。
- **page_update**（集約ページ・店舗ブログ・公式info）: 再販関連の本文行を抽出して正規化ハッシュ化し、
  新規に現れた「実質情報の行」だけを差分つきで通知。
- **pokecen_news_ids**（ポケセンオンライン）: TOPページの記事ID差分→個別記事の本文取得で判定。
- **pokecard_official_list** / **onepiece_news**: 公式APIの商品・記事一覧の差分で新商品・ニュースを検知。
- **gdb_soldout**（ガンプラ・現在未使用）: GunplaDatabase の `shop_status_container` ブロックの
  `soldout` クラス/「売切」テキストの有無で店舗別在庫を判定。ヨドバシ.com はBot対策で直接監視不可のため
  採用していた方式。2026-07-10のガンプラ除外以降は `WATCH_ITEMS` に対象が無い。

### ⚠️ 重要な注意（検証の前提）
- 検知される在庫には **Amazon等の転売価格**が含まれる場合がある。
- **通知が来たら「定価（各監視の `retail_price`・ポケカBOXなら5,400〜6,000円等）で買えるか」を
  必ず人間が確認する**こと（通知文に明記）。
- 定価で買えなければ見送る（＝Q1「定価入手の再現性」の検証にならないため）。

## 🔔 通知が来たら（検証の手順）

1. **まず価格を確認** — 通知本文に載る定価（例: ポケカBOX 5,400〜6,000円）で買えるか？（Amazon等は転売価格の場合あり）
2. 定価なら**即購入手続き**（数分で完売の争奪戦）
3. **記録**（docs/07 のKPI）: 何回目の挑戦で買えたか・所要時間・売り切れまでの分数
4. 確保できたらフリマ出品 → 売却日数・実際の手残りを記録

## 📝 監視対象の追加・変更

- **anime-matsuri の抽選まとめページは手作業不要**: 毎朝の自動発見が未監視ページを
  そのまま動的監視に登録する（`AUTO_WATCH_ENABLED=True`・最大 `AUTO_WATCH_MAX`=40件）。
  外したいものがあれば Claude Code に伝える
- それ以外（東映公式の商品ページ・店舗ブログ・公式ニュース等）は `config.py` の `WATCH_ITEMS` に
  `method` / `url` / `retail_price` / `release_date`（1年半で自動失効）/ `key` を持つ辞書を追加する。
  必要に応じて項目フラグ `require_keywords`（商材名の必須語）・`strict_actions`（行動語必須）・
  `suppress_item_url`（監視元URL行を出さない）・`no_search_fallback`（検索URLを付けない）を付ける
- 対象は**カードゲーム商品（主軸はポケカ）**に限る。方針: 正規新品・未開封のまま売れる・非酒類。
  サプライ類や発売から1年半超の旧弾は追わない（NOTIFICATION_RULES.md 参照）

## ⚠️ 注意

- サイトへの負荷に配慮し、商品ごとに1.0秒間隔（`REQUEST_INTERVAL`）でリクエストし、
  同一ページへのアクセスは約7〜8分に1回に抑えている。
- あくまで個人利用の在庫通知・検証目的。
